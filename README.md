# Saurabh Gupta Portfolio

This portfolio showcases some of the products and applications I’ve worked on as a Flutter developer, including mobile apps, AI-powered tools, and production-level systems.

I wanted the portfolio to feel more like a real product than a basic template, so the focus was on clean UI, smooth interactions, reusable architecture, and detailed project showcases.

Built with Next.js, React, Tailwind CSS, and Framer Motion.

---

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## Featured Projects

### SpeechFlo
AI-powered speech platform with speech-to-text and text-to-speech functionality featuring a modern AI-inspired interface and interactive experience.

### LocalRAG API
Retrieval-Augmented Generation API built using FastAPI and Ollama with document ingestion, semantic search, and contextual AI workflows.

### I Unite – Abroad Study B2B CRM App
Role-based CRM platform for study-abroad consultants with lead management, JWT authentication, pagination, push notifications, and real-time updates.

### EduVizz – School Management App
School management and communication platform with role-based access and real-time features for students, teachers, and administration.

### Tech Junction – E-commerce App
E-commerce application for mobiles, laptops, and accessories with product listing, cart flow, and order management features.

### Company Website – Legal Pages & Maintenance
Worked on legal pages, Firebase hosting, maintenance, and production updates for the company website.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open in browser:

```bash
http://localhost:3000
```
